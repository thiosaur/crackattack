Sixth beta of **Crack Attack! — Back From The Stack**.

- **Terminal version, to serve a game**: `--replay` starts a new game after a lost one,
  `--idle-timeout SECS` and `--max-time SECS` end a session that is idle or too long, and a
  dropped connection (for example an ssh login that goes away) ends the game by itself. The
  display and the game are unchanged.
- **Downloads**: a static Linux build of the terminal version
  (`crackattack-terminal-VERSION-linux-x86_64-static.tar.gz`) runs on any distribution and in a
  minimal container, and each release now carries a `SHA256SUMS` file with the checksum of every
  file.

Network play stays compatible with beta 5 (and beta 4 and 3, but not beta 2). Packages installed
from beta 5 keep their settings, scores and ranking.

This is a beta: please report problems on the [issue tracker](https://github.com/thiosaur/crackattack/issues).
