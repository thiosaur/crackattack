Third beta of **Crack Attack! — Back From The Stack**.

- **Computer opponent on the grid**: play against the computer in three levels (Easy,
  Medium, Hard), with a small preview of the opponent's board.
- **New menu graphics**.
- **Network play**: this version is **not compatible with beta 2** (network protocol 4).
  The LAN list now shows players running another version greyed out as *incompatible
  network version*, and a failed connection says whose version of the game is older.
- **Updates screen**: redesigned, with a single button to download the new version and an
  *Automatic checks* option.
- **Downloads**: the files are now named `-installer` (macOS disk image, Windows installer,
  Linux AppImage) and `-portable` (plain archives).
- **Terminal version**: the text version (`crackattack-terminal`, built from source) is
  redone: smooth movement, pause, danger bars and a summary at the end.

Packages installed from beta 2 keep their settings, scores and ranking.

This is a beta: please report problems on the [issue tracker](https://github.com/thiosaur/crackattack/issues).
