Second beta of **Crack Attack! — Back From The Stack**.

- **Installers**: the macOS disk image (drag the app into *Applications*), the Windows
  installer and the Linux AppImage are now part of the release, next to the plain archives.
- **Network play**: the game port now stays the same from one game to the next on macOS and
  Linux, so the address saved in your ranking stays valid for *Quick reconnect*.
- **Translations**: the rules now state the seven-second delay before a lost game, the
  ranking's "just now" label now says "less than an hour ago", and many wording fixes in
  English, German, Spanish, Italian, Polish, Russian, Chinese, Japanese, Korean and Turkish.
  Please keep reporting anything that reads wrong.

Packages installed from beta 1 keep their settings, scores and ranking.

This is a beta: please report problems on the [issue tracker](https://github.com/thiosaur/crackattack/issues).
