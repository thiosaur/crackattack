Fifth beta of **Crack Attack! — Back From The Stack**.

- **Terminal version, now a download**: the text version (`crackattack-terminal`) is built for
  Windows, macOS and Linux and attached to each release: one small executable, no installation,
  no game data. It is a solo game only.
- **Terminal, smaller screens**: a new compact display (`--compact`, chosen by itself when the
  terminal has fewer than 28 lines) fits the whole game in 80x24. The display is also several
  times faster to draw.
- **Under the hood**: the game engine is tidier (the unused old computer-player code is gone,
  attacks received over the network are validated by the engine, and the danger bars read
  the defeat countdown from the engine). The game plays exactly as in beta 4.

Network play stays compatible with beta 4 (and beta 3, but not beta 2). Packages installed from
beta 4 keep their settings, scores and ranking.

This is a beta: please report problems on the [issue tracker](https://github.com/thiosaur/crackattack/issues).
