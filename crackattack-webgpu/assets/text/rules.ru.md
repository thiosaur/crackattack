# Как играть

Цель: в дуэли завалите соперника мусором, а в соло наберите как можно больше очков.

- Перемещайте курсор стрелками.
- Курсор выбирает **две соседние клетки по горизонтали**. Меняйте их блоки местами (по умолчанию Пробел). Блок можно также поменять с пустой клеткой.
- Выстройте **3 или больше блоков** одного цвета по горизонтали или вертикали, чтобы убрать их.
- Исчезновения подряд образуют **цепочки**; несколько линий сразу — **комбо**. Цепочки и комбо отправляют мусор сопернику.
- Удерживайте Enter, чтобы быстрее поднимать стопку.
- Если стопка доходит до верха, у вас есть **семь секунд**, чтобы её опустить, иначе вы проиграете.
